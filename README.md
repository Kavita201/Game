# Tic Tac Toe and Guessing Number Game in Python

## Overview
This project contains two simple games implemented in Python:
1. **Tic Tac Toe**: A classic two-player game where players take turns marking a space in a 3x3 grid.
2. **Guessing Number**: A single-player game where the player attempts to guess a randomly generated number within a certain range.

## Features
### Tic Tac Toe
- **Two-player mode**: Compete against a friend.
- **Interactive Console Interface**: Easy input for moves in the terminal.
- **Win and Draw Detection**: The game checks for win conditions and recognizes draws.

### Guessing Number
- **Single-player mode**: Guess a randomly generated number.
- **User Feedback**: The game provides hints if the guess is too high or too low.
- **Custom Range**: Set the range for the random number at the start of the game.

## Technologies Used
- Python 3.x
